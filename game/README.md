# UMA STABLE プログレス — 競走馬メダルゲーム(ブラウザ版)

競走馬メダルゲームというジャンルの仕組み(メダルベット・オッズ・育成・配合・継承)を参考にした、
**個人利用目的のオリジナル・ファンメイド作品**。PC/スマートフォンのブラウザだけで動作する
(ビルド不要・サーバ不要・オフライン可)。

> ⚠ 本作は特定の商用ゲームとの接続・関係は一切なく、商用ゲームの名称・ロゴ・映像・音楽・
> プログラムは使用していません。実在の競走馬名・レース名は事実情報として使用しています。
> 再配布・商用利用はしないでください。
> ゲームシステムの数値・仕様は `../docs/starhorse-progress-returns-research.md` の
> 調査(ブログ・攻略情報等の公開情報)を参考にした近似値です。

## 遊び方

### 起動
- **PC**: `game/index.html` をブラウザで開くだけ(ダブルクリックでOK)。
- **スマホ**: リポジトリをGitHub Pages等で公開して `…/game/` を開くか、
  PCで `cd game && python3 -m http.server 8000` を実行して同一Wi-Fiから `http://<PCのIP>:8000` にアクセス。
- セーブはブラウザのlocalStorageに自動保存。設定タブから書き出し/読み込み可能。

### ゲームの流れ(1週=1サイクル)
1. **厩舎タブ**: 所有馬ごとに今週のプランを設定(調教・飼葉/放牧/休養/出走登録)。
2. **レースタブ**: 今週のレースを選んで馬券を購入し、観戦。
3. **「次の週へ」**: プラン実行・未観戦の自馬レース自動処理・週送り。

### 馬券(8種+ライド)
単勝・複勝・枠連・馬連・馬単・ワイド・三連複・三連単。ベット単位は 1/5/10/50/100枚。
**メイクライド**=1着馬(複勝ライドは3着内)を当て続け、払い戻しを次レースへ自動的に賭け続ける連勝式。
降りるまで増え続けるが、外せば全額喪失。オッズは出走馬の実力から算出(ペイ設定 90/88/84/80% を設定タブで変更可)。

### 育成(オーナーゲーム)
- **生産**: CPU種牡馬×繁殖牝馬(または引退した自分の馬)を配合。メダル40枚。
  - 継承型: **H/H**(ブレ大・一発狙い)/**平均**(中庸)/**堅実**(安定)
  - 誕生時に牧場長のコメントで素質が示唆される(名馬コメ等は条件戦無敗クリア時のみ)
- **素質**: MAX上/MAX中/MAX下/準MAX/2落ち/3落ち/4落ち の隠しランク。
  **弥生賞→皐月賞(牝馬は桜花賞)のオッズで自動判定**される(判定表はペイ設定に連動)。
- **調教**: 芝(SP)/ダート(PW)/プール(ST・漬け)/森の馬道(疲労回復)/特殊(全能力)/癒しの音楽(スタート)/極秘調教。
- **脚質7種**: 逃げ/先行/差し/追込 + 特殊(大逃げ/まくり/自在)。
  極秘調教×餌で変更: 大根=逃げ(×3で大逃げ)、リンゴ=先行、人参=差し(×3でまくり)、角砂糖=追込、ビール=自在。
- **寿命**: 厩舎在籍120週で引退。調教・飼葉・出走・放牧をした週だけ残り週が減る(何もしなければ温存)。
- **継承**: GⅠ勝利 or 残80週以下で継承引退可。残り週を大量に残した早期引退は「まだコメ」ペナルティ。
- **漬け育成**: プール調教を20週以上(60週以上でさらに)積んでから引退させると次代の素質が上がる。
- **代重ね**: 自家製馬を親に使い世代を重ねるほど素質MAXに近づく。

### レース
- 年間52週のレーシングプログラム(実名重賞54戦+毎週の新馬/未勝利/条件/OP)。
- 三冠(皐月賞→ダービー→菊花賞)、障害(中山大障害・FAR EAST GRAND JUMP等)、
  最上位の**WBC**(5頭立て・賞金最大)を収録。
- 2D横スクロール描画+実況テキスト。脚質による展開(大逃げの直線失速、まくりの3角発進など)を再現。
- 賞金は5着まで。馬場状態(良/稍重/重/不良)と重馬場適性が影響。

## ファイル構成
```
game/
├── index.html       エントリポイント
├── css/style.css    スタイル(ダークテーマ・レスポンシブ)
└── js/
    ├── data.js      マスタ(レース/CPU馬/騎手/調教/賞金/判定表)
    ├── horse.js     馬モデル・生産・育成・引退継承
    ├── race.js      出走表・オッズ(Plackett-Luce)・シミュレーション・払戻
    ├── state.js     ゲーム状態・週進行・セーブ(localStorage)
    ├── ui-util.js   DOMユーティリティ
    ├── ui-race.js   レースタブ(馬券/Canvas観戦/結果)
    ├── ui-stable.js 厩舎/生産/記録/設定タブ
    └── main.js      起動・ナビゲーション
```
