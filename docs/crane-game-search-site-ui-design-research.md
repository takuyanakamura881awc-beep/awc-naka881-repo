# クレサーチ UI/UXデザイン調査と改訂方針

> 目的：投稿で成り立つUGCサービスとして「直感的に操作でき、最近のトレンドで、実績のある使いやすさ」を実現するため、他業界（フリマ・グルメ・口コミ・地図・ゲーミフィケーション）の実績あるUXパターンを調査し、クレサーチに翻案する。
> 結論：クレーンゲーム特化の直接競合UIは存在しない。よって**参照先を他業界から意図的に輸入する**のが妥当。以下のTOP施策を採用し、プロトタイプを「マーケLP」から「実操作がわかるモバイルアプリUIモック」へ発展させる。

## モバイル画面構成（推奨）

### ボトムナビ（5項目、中央に投稿を強調）
1. **ホーム**（現在地ベースの新着フィード・鮮度順）
2. **さがす**（地図⇄一覧トグル＋チップフィルター）
3. **＋投稿**（中央強調・FAB的な大アイコン＝親指ゾーン）
4. **マイページ**（投稿履歴・ポイント/レベル/バッジ・閲覧権の残日数）
5. **お知らせ**（フォロー店の新着・鮮度切れ警告・リアクション）

### 画面遷移
```
[ホーム/検索バー]
  └→ [検索結果：地図/一覧トグル ＋ チップフィルター（景品ジャンル/設定/価格帯/鮮度）]
        └→ [店舗詳細（ボトムシート半展開）]
              ├→ [景品一覧（鮮度バッジ付きカード）] → [景品詳細（金額推移・投稿者コメント・鮮度）]
              │        └→ 未投稿ならゲート：一部ぼかし＋「あと1件で解放」＋月額
              └→ [この店舗に投稿]（位置情報は自動セット）
```
検索結果の段階では最低限（店舗名・距離・景品ジャンル・最終更新からの経過）は必ず見せ、**詳細に踏み込んで初めてゲートを出す**（早すぎるゲートは離脱の主因）。

### 投稿フロー（4ステップ・FAB起点・進捗バー付き）
1. **撮影/選択** … 景品棚 or 価格表示を撮る（カメラ即起動が既定、ギャラリーも可）
2. **自動補完の確認** … 位置情報から店舗を自動サジェスト（タップ確定）、OCR候補で金額・景品名を仮入力、時刻は自動
3. **チップ選択** … 設定（フック/アーム/橋渡し/確率機）・価格帯・体感の渋さ（甘い/普通/渋い）。自由コメントは折りたたみ（プログレッシブディスクロージャー）
4. **完了** … 「＋◯pt獲得」「この店の全情報が解放」をその場で見せて次の投稿へ動機づけ

ステップは3〜4が上限目安（NN/gウィザード指針）。途中離脱でも下書き保存。

## 2024〜2025 モバイルUIトレンド（採用 / 回避）

**採用**：ボトムナビ＋親指ゾーン設計／カードフィード＋チップフィルター（カード内は「店舗・景品・価格・鮮度」の4要素に絞る）／地図×一覧トグル／スケルトンローディング／プログレッシブディスクロージャー／太めタイポ＋大きめ余白（屋内外の可読性にも実利）／控えめなマイクロインタラクション。

**回避（やりすぎ）**：
- **グラスモーフィズム／Liquid Glass的な過度な半透明・ブラー** … 可読性を損なう（NN/gがiOS 26 Liquid Glassのユーザビリティ低下を指摘）。金額・鮮度など数値の視認性が命の本サービスには不適。
- **全面ダークモード固定** … 屋外視認性・共有時の見やすさを考え、ライト基調＋ダーク選択制に。
- **フリーテキスト依存の投稿フォーム** … 入力の手間が離脱の最大要因。チップ/選択式に寄せる。
- **完全ブロック型ゲート** … OpenWorkでも無料代替を複数用意。0/1ゲートは初回離脱を招く。
- **過剰なゲーミフィケーション演出**（毎回の大きなコンフェッティ、連続ログイン催促）… 鬱陶しさが勝ちダークパターン批判の対象に。
- **相対時刻の秒単位表示／地図ピンの過密表示（クラスタリングなし）**。

## クレサーチ独自の勘所（提案）
- **情報の"減衰"を視覚化**：鮮度が古い投稿は自動でグレーアウト・折りたたみ。複数投稿で金額が急変したら「設定変更の兆候」アイコンを出す（他社に直接例がない＝差別化ポイント）。
- **検索チップと投稿チップの語彙統一**：ユーザーが覚える語彙を1セットに。
- **相場サジェスト**：店舗×景品の過去投稿から1プレイ価格の初期値を提示（駿河屋の"相場を調べる手間を排除"の翻案）。
