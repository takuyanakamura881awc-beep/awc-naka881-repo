# クレサーチ 設計仕様書（画面・表示項目・全体プラン）＝デザイン委託用ハンドオフ

> 目的：本書1冊で、別のデザイナー/AIが**ビジュアルデザインを一から起こせる**ように、事業目的・全体プラン・情報設計・全画面の表示項目・機能ルール・データ項目・状態遷移をまとめたもの。

## 0. サービスの目的（これが全ての前提）

- **一言**：クレーンゲームの景品が「**どの店に・いくらで・いつの情報か・誰の情報か（信頼度）**」わかる、**利用者投稿型**の景品検索アプリ。
- **中核体験**：欲しい景品名で検索 → 近くの店の在庫・設定・1プレイ価格・鮮度・投稿者の信頼度を見て、ムダ遠征と“溶かし”を防いで遊びに行く。
- **運営者の狙い**：**副業・趣味で小遣い／匿名で身元を晒さない／運営は低負荷**。大きな稼ぎは狙わない。
- **成り立ち**：情報はユーザー投稿。詳細を見るには投稿を促す（軽めのゲート）。運営は保守中心。

## 1. 全体プラン（事業の骨子）

### 収益モデル（確定）
- **広告（ディスプレイ・脇役）＋ アフィリエイト（主力：オンラインクレーンゲーム登録・プライズ物販）**。
- **サブスク（月額課金）は初期はやらない**＝特商法の氏名・住所公開を避ける（匿名運用）。将来、法人化/バーチャルオフィス整備後に後付け可。
- **B2B（店舗向け有料）は棚上げ**（送客実績が出るまで成立せず、営業負荷が高い）。

### 収益見込み（広告＋アフィリのみ）
- 公開1年：月 数千〜3万円／2年：月 3〜15万円（うまくいけば）。**大化け（月100万〜）は構造的に非現実的**。現金コストは極小、実コストは運営者の時間。

### 情報の3レベル（安全設計の核・デザインにも影響）
| レベル | 内容 | 扱い |
|---|---|---|
| **L0 一般論**（店を名指ししない：取り方のコツ・景品図鑑・オンクレ比較） | SEO・アフィリの背骨（＝読みもの） | **載せる** |
| **L1 事実の在庫情報**（どの店に・いくらで・いつ・設定タイプの“事実”） | サービスの核（＝景品カード） | **載せる** |
| **L2 評価/攻略/断定**（「渋い」「イカサマ」「攻略手順」） | 店が損→通報/営業妨害リスク | **扱わない** |

### 主要リスク（回避策込み）
- 情報の陳腐化（数時間で古くなる）→ 鮮度エンジン（減衰・自動アーカイブ・追認）。
- 店舗との利益相反→ L1（送客＝店にプラス）に留めL2回避、事実限定、削除窓口。
- 著作権（景品画像）→ 写真は任意・外部リンク優先・申立てベースで即削除。
- 匿名運用→ サブスクを出さない限り特商法の氏名住所公開は不要。プラポリ＋ステマ表記（PR）は必要。

## 2. 情報アーキテクチャ / ナビゲーション

- **ボトムナビ 5項目**：`ホーム` / `さがす` / `＋投稿`（中央・FAB強調） / `お知らせ` / `マイページ`。
- 主要導線：`ホーム(発見)` → `景品カード` → `景品詳細(＋ゲート)` → `投稿`。`さがす`は検索・絞り込み・地図。
- 画面遷移の原則：**一覧・店・景品・エリア・ざっくり在庫は誰でも閲覧可**（新規の入口・SEO）。**正確な設定・投稿者コメント・最新の鮮度=詳細に踏み込んで初めてゲート**（早すぎるゲートは離脱）。

## 3. 画面ごとの表示項目・機能（全画面）

### 3-1. 共通要素
- **アプリヘッダー**：戻る(＜) / ロゴ（ブランドマーク＋「クレサーチ」） / テーマ切替（ライト/ダーク）。
- **ボトムナビ**（上記5項目、アクティブ状態を明示）。
- **トースト**（操作フィードバック。実通信なしのモック文言例：「※プロトタイプのためリンクはありません」）。
- **マスコット**（クローのキャラ）：空状態・投稿完了・フッターなどに登場（ブランド差別化。今後の拡張ポイント）。

### 3-2. ホーム（発見フィード）
- **現在地バー**：現在地/エリア名＋範囲（例「仙台駅周辺 1.5km」・変更可）＋「直近◯時間以内 ◯件」の鮮度サマリ。
- **リード**：見出し「いま、近くで見つかってる景品」＋サブ「情報はユーザー投稿です。鮮度と信頼度を見て遊びに行こう。」
- **並び替え**：`新着順` / `近い順` / `信頼度順`（トグル、既定=新着順）。
- **景品カードのフィード**（下記3-8のカード仕様）。
- **読みもの（L0）レール**：横スクロールの記事カード（「取り方のコツ」「景品図鑑」「オンクレ比較」等、`編集部`バッジ付き）＋「すべて見る」。
- **フィード末尾**：マスコット＋一言（例「今日の新着はここまで。あなたの1投稿が、だれかの1勝になる。」）＋CTA「見つけた景品を投稿する」。

### 3-3. さがす（検索・絞り込み・地図）
- **検索バー**：景品名で検索（プレースホルダ例「景品名でさがす（例：ちいかわ）」）。
- **絞り込みチップ**（グループ）：
  - ジャンル：`ぬいぐるみ / フィギュア / お菓子 / 雑貨`
  - 設定タイプ：`橋渡し / アーム / フック / 確率機`
  - 価格帯：`¥100 / ¥200 / ¥500`
  - 鮮度：`本日 / 3時間以内 / 12時間以内`（表現は要検討）
  ※検索チップと投稿チップの語彙は統一する。
- **件数表示**：「◯件みつかった」。
- **表示切替**：`一覧` / `地図`（セグメント）。
- **一覧**：景品カードのグリッド/リスト。
- **地図**：周辺地図＋店舗ピン（ピンに価格 ¥◯◯）＋現在地マーカー。ピンタップ→店舗プレビュー（店名・景品数・最寄り鮮度）をボトムシート等で表示。ピンは密集時クラスタリング。

### 3-4. 景品詳細（＋投稿ゲート）
- **ヒーロー画像領域**：写真がない前提。モノグラム等で表現。**「写真はまだありません（撮影禁止店の可能性）」の注記**。
- **[必須]景品名 / 店舗名 / 距離 / 「地図で見る」リンク**。
- **[必須]情報グリッド（2×2目安）**：
  - `1プレイ` … ¥価格（/回）
  - `設定タイプ` … 橋渡し 等
  - `情報の鮮度` … 「◯分前」＋新しさ（新しい/やや古い/古い）
  - `みんなの追認` … 「まだあった ◯件」／否定報告の有無
- **[必須]この情報の投稿者**：アバター（モノグラム）＋ハンドル＋`Lv.◯`＋`信頼度 高/中/低`＋**根拠**（例「直近◯投稿の追認率◯% / GPS整合 / 写真投稿率◯%」）。
- **投稿ゲート(状態: 未解放)**：投稿者コメント・詳細設定などを**ぼかし**、上に「**一覧・店舗・景品・エリアは登録なしで見られます。最新の詳細を見るには、直近に1件投稿を。**」＋**進捗ゲージ（あと◯件で解放）**＋CTA「**投稿して解放する**」。**月額導線は出さない**。
- **[必須]追認ボタン**：`まだあった👍(件数)` / `もう無かった👋`。押下で件数変化＋鮮度更新（+ポイント）。
- **[任意]台のくわしい情報**（詳細の続き）。

### 3-5. 投稿フロー（3ステップ・写真は任意）
- **共通**：進捗バー（STEP ◯/3）、戻る/つぎへ、途中離脱で下書き保持（任意）。**必須項目が揃うまで「つぎへ」は不活性**。
- **（初回のみ）アカウント案内**：「アカウント作成で投稿できます（メール / SNSログイン・ハンドルは匿名でOK）」＋スキップ可。
- **STEP 1「どこのお店で見つけた？」**：現在地から近い順の店舗リスト（店名・距離・徒歩分数・選択ラジオ）＋「現在地から探し直す」。（＝店舗はGPS候補から選択。無ければ追加）
- **STEP 2「なにを見つけた？」**：景品名（入力＋クイック候補チップ）／ジャンル（チップ）／台の設定タイプ（チップ：橋渡し・アーム(3本爪)・フック・確率機）／1プレイの価格（¥100/¥200/¥500 等）。**自由記述は最小**。
  - **写真は任意**：「写真を追加（任意）」＋「写真なしで進む」＋安心コピー「撮影禁止のお店でもOK」。写真ありの時のみ自動補完（店舗/金額/景品名のOCR・AI候補）を提示。
- **STEP 3「投稿完了」**：獲得演出（+◯pt・軽いお祝い）＋「この店舗の詳細が◯日間 解放されました」＋「もう1件投稿」/「解放された情報を見る」。

### 3-6. マイページ
- **プロフィール**：アバター（モノグラム）＋ハンドル（匿名 @xxxx）＋`Lv.◯`（称号）＋レベル進捗バー（次のLvまで あと◯pt）。
- **統計タイル**：`ポイント` / `投稿(件)` / `追認された(件)`（数値は等幅）。
- **詳細閲覧パス**：状態「有効・あと◯日」＋説明「1回投稿するたびに◯日にリセット。切れると詳細の一部が非表示に。」＋CTA「投稿して延長する」。（＝軽めゲートの残日数。月額は「将来提供予定」表記に留める）
- **バッジ・称号**：獲得済み（例：はじめての投稿・追認マスター・鮮度番長・遠征ハンター・確率機マイスター・「◯◯(エリア)の主」）＋未獲得（グレー）＋「すべて」。
- **今週の貢献ランキング**：Top3（順位・ハンドル・Lv・今月pt）＋「あなた：◯位」。

### 3-7. お知らせ
- **通知リスト**（アイコン＋本文＋相対時刻＋未読ドット）。種類例：
  - フォロー中の店に新着景品／自分の投稿に「まだあった」が付いた／投稿が◯時間経過（鮮度切れ間近・再確認促し）／自分のメモに「たすかった」が付いた／貢献ランキングにランクイン。

### 3-8. 景品カード（一覧の1件・最重要コンポーネント）
**[必須]表示項目**：
- サムネイル（写真なし前提＝モノグラム等）
- 店舗名 ＋ 距離（例 350m）
- 景品名
- 設定タイプ（チップ：橋渡し/アーム/フック/確率機）
- 1プレイ価格（¥◯◯/回・等幅数字）
- 鮮度（「◯分前」＋新しさの色。古い投稿はトーンダウン）
- 投稿者：`Lv.◯ 称号` ＋ 信頼度（高/中/低）
- 追認ボタン：`まだあった👍(件数)` / `もう無かった👋`
**(状態)**：`gated`（一部項目をぼかし）／`stale`（鮮度が古く全体を減光）。

### 3-9. 読みもの（L0：一般記事）
- **一覧**：記事カード（アイコン＋タイトル＋`編集部`バッジ）。カテゴリ例：取り方のコツ／景品図鑑／オンクレ比較。
- **記事詳細**：タイトル＋バイライン（クレサーチ編集部・日付・カテゴリ）＋本文（見出し＋段落）＋**末尾にアフィリ導線（「PR」表記必須＝ステマ規制対応）**（例「オンラインでも遊べる[PR]」「通販で探す[PR]」）＋**免責「特定店舗の設定を保証しない」**（＝L2回避を明示）。

## 5. 機能ルール（デザインが従うべき挙動）

- **鮮度エンジン**：`posted_at`で相対時刻表示（最小粒度=分、“0秒前”回避）。tier色分け（新→中→古）。古い投稿は減光/後方。一定期間超は既定検索から外し「過去ログ」へ。「まだあった/もう無かった」の追認で鮮度更新（減衰リセット）。否定報告が閾値でアーカイブ。
- **信頼度スコア**：投稿者実績（後で追認された率/通報された率）×同一台への複数一致（多数決）×GPS整合×（任意で写真）で算出。**高/中/低＋根拠**を表示。信頼度の高い情報を上位化（並び替え「信頼度順」）。
- **投稿ゲート（軽め）**：一覧・店・景品・エリア・ざっくり在庫は開放。詳細（正確な設定・投稿者コメント・最新鮮度）は「直近に1件投稿」で解放。**月額は初期なし**。
- **投稿UX**：写真必須にしない。店舗はGPS候補から選択（無ければ追加）。設定/価格/景品はチップ・選択式中心、自由記述は最小。
- **モデレーション**：即時反映＋スコアリング主軸。相互レビューは“事後の追認/訂正”に格下げ。通報ボタン＋閾値で自動非表示。
- **不正対策**：GPSチェックイン、新規アカウントの重み減衰、結託検知、レート制限、**ポイントは換金不可（閲覧権/称号のみ）**。
- **コンテンツ方針**：L2（店名指しの設定晒し・攻略・「詐欺/ぼったくり」等の断定）を投稿ガイドラインで禁止、事実（価格・日時・取れたか・設定タイプ）に限定。
- **法務・表記**：アフィリは「PR」表記（ステマ規制）。プライバシーポリシー・利用規約・削除/権利侵害の申立て窓口を用意。景品画像は申立てベースで即削除。上限超過景品・転売誘導は非表示。

## 6. 現行デザインの決定事項（＝出発点。刷新可・参考として）

> 別AIがビジュアルを起こす際の“現状の答え”。守ってもよいし、より良くしてもよい。

- **世界観**：温かポップ（クリーム地＋コーラルのアクセント＋サニーイエローの差し色。ダークは茶系の暖色）。
- **フォント（役割分担＝あつ森方式）**：見出し・タブ・カードの景品名・ロゴ＝**丸ゴシック**（Zen Maru Gothic／ロゴは Mochiy Pop P One）。長文（読みもの本文・リード・注意書き）＝可読性重視の**Noto Sans JP**。価格・pt・距離・順位＝**等幅数字（tabular-nums）**。いずれもOFL等で商用可・Webフォント埋め込み前提。
- **写真なしカードの見せ方**：**モノグラム**（景品/店の頭文字＋ジャンル別の淡いカテゴリ色＋小さな線アイコン）。単色べた塗りでなく**微グラデ＋ドット質感＋内側ハイライト＋角丸22px**でリッチに。**絵文字を機能アイコンに使わない**（線アイコンを自作）。
- **配色原則**：白/クリームの広い余白＋アクセント1色（面積≦10%・CTA/新着/選択に限定）。8ptの余白ルール。影は極薄＋境界線。角丸は「カード/ボタン/丸アバター」の数値に固定。左揃え基調だが、**現行は景品カードを中央揃えの縦カード**にしている（運営者の希望）。
- **鮮度/信頼度の視覚言語**：鮮度=信号色（新=緑系/中=黄系/古=グレー、色だけに依存せずテキスト併記）。信頼度=高/中/低のバッジ＋根拠。
- **参考実装**：`docs/prototype/app-redesign.html`（自己完結HTML・ライト/ダーク・モック動作）。公開プレビュー（Artifact）URLは運営者が保有。

## 8. デザイン委託時の注意（この事業ならではの制約）

1. **写真前提にしない**（撮影禁止店が多い）。画像なしでも成立する見せ方を。
2. **鮮度が命**：情報が「何分前か・新しいか」を最優先で目立たせる。
3. **信頼度＝誰の情報か**を各所で可視化（レベル・信頼度・根拠）。
