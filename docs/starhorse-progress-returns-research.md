# スターホース プログレス リターンズ（スタホR）調査レポート

> 目的：実機ゲーム「スターホース プログレス リターンズ」のコンパニオン／管理アプリを設計するための、ゲームシステムの体系的整理。
> 手法：5アングルに分けた並列Web調査（能力パラメータ／育成・調教／配合・血統／レース・馬券・メダル／セーブ・記録ニーズ）。

## ⚠ 調査上の制約（確度に直結・必読）
- **本文直接取得が不可**：sega.jp・ameblo・Yahoo知恵袋・medalgamefan・hihimaru・momomaru 等の主要日本語ソースは、この環境で **WebFetch が一律 HTTP 403**（archive.org も遮断）。全ての事実は **検索エンジンのスニペット要約** に基づき、原文逐語の確認はできていない。**数値・固有名詞は実機／原文での再確認を推奨**。
- **版（バージョン）混在が最大リスク**：ネット上の濃い攻略情報は**ほぼスタホ4（2019/2020〜）**に集中。スタホR（Progress Returns＝2009稼働の旧世代）は別仕様。本書では【R】＝スタホR固有確認、【4】＝スタホ4仕様（R不明）、【共通】＝シリーズ共通と推定、を明示。

## 0. 版の位置づけ
- 系譜（諸説あり・要確認）：初代(2000) → Progress(2003) → StarHorse2(2005) → **Progress Returns / スタホR(2009)** → StarHorse3(2011) → StarHorse4(2019/2020)。
- スタホRの特徴：初代の**障害レース復活**（中山大障害ほか実名＋オリジナル「FAR EAST GRAND JUMP」）、ディープインパクト・ウオッカ等の名馬追加。
- **重要**：現代の公式連動Web「SH4.NET」や既存の「配合シミュレータ」アプリは**スタホ4向け**。スタホRには同等の連動サービスは確認できず（＝固有データが乏しい／＝管理ツールの空白でもある）。
- 出典: sega.jp/history/arcade/product/15045/（スタホR）, /8837/（Progress）

## 1. 馬の能力・適性
### 表パラ（表向き能力）【R／共通】
- **スピード(SP) / スタミナ(ST) / パワー** が基本。SH3では**瞬発力**も調教対象。
- SP・ST・パワーは**相反**しやすい（一方を上げると他方が下がる傾向）＝プレイヤー考察。
- **表パラと距離適性は別軸**（SPが高い＝短距離、ではない）。
- 出典: ameblo/momomarustarho 11800380173, umashibiko 11434951854, sega sh3 owner2

### 距離適性
- 区分：**短距離 / マイル / 中距離 / 長距離**。
- 表記：**適性距離レンジ（◯◯◯◯m〜◯◯◯◯m）**型が主【4で明示、Rは推定】。
- 出典: sega sh4 tsujouseisan-tekisei, 知恵袋 q1338043788

### 馬場適性
- **芝 / ダート**＋**道悪**（重・不良への強さ）。馬場状態語彙：良/稍重/重/不良。
- 表記は **D〜SS【4】**。Rの表記体系は未確認（数値/記号の可能性）。

### 脚質【R固有・確度高】
- 通常4種：**逃げ / 先行 / 差し / 追込**。特殊3種：**大逃げ / まくり / 自在**。
- 決まり方：初代はランダム、2世代目以降は親から継承しやすい。
- **変更法（R固有データ）**：極秘調教＋餌 … 逃げ=大根 / 先行=リンゴ / 差し=人参 / 追込=角砂糖 / 大逃げ=(極秘+大根)×3 / まくり=(極秘+人参)×3 / 自在=極秘+ビール。
- 騎手にも脚質の得意/不得意があり、馬の脚質に合わせた騎手選択が重要。
- 出典: ameblo/ponyo-sakanoko 12542276899, 知恵袋 q101325425

### 気性・体質・その他【主に4】
- 気性：穏やか/普通/荒い/激しい（調教の強弱で変動）【4】。
- 体質（疲労の蓄積/回復）、勝負根性、スタート、瞬発力 が独立項目【4】。Rの細分は未確認。

### 素質（隠しグレード）【R固有・確度中】
- 表パラとは別に**素質ランク**：**MAX上 / MAX中 / MAX下 / 準MAX / 2落ち / 3落ち / 4落ち**。
- **皐月賞のオッズで判定**する慣習（例：2.8→MAX上、2.9→MAX中、3.0→MAX下、3.1→準MAX）。
- 「表面の素質と内部能力は別設定」＝二層構造との指摘。
- 出典: medalgamefan topicid=91, 知恵袋 q10127045115 / q13249863218

## 2. 育成・調教
- **週進行**。所有馬に**残り週（寿命）**。調教・飼葉・出走登録・出走のいずれかで残り週を消化。何もしなければ減らない（温存可）【共通/4】。
- 調教・飼葉は**1週各1回**。放置でもAI調教が入り極端に崩れない【共通】。
- 出走間隔の標準は**中2週**（間を詰めるとペナルティ的）【4】。
- **漬け（プール漬け）**【R中核】：出走させず調教＋飼葉でメダル投資し続け、引退で**次代素質を底上げ**する育成法。期間は20〜120週まで諸説（標準値なし）。プール調教＝心肺/スタミナ系強化。
- **まだコメ／コメ消し**【4、R類似俗称】：残り週が多い（例:41週以上）状態で引退するとペナルティ。規定レース数消化で解禁。素質馬ほどコメ消えまで多く走らせる必要。
- 調教メニュー【4】：芝/ダート/プール、森の馬道（疲労回復＋馬体重）、特殊調教（全適性UP）、癒しの音楽（スタート/遠征）。Rのメニュー一覧は未確認。
- 飼葉【3/4】：通常/勝利（レース1週前）/牧場/特別。酒系・高級は疲労回復大。
- 放牧【3/4】：疲労回復・馬体重・調子リセット。最低4週、スタミナ微減。
- 3歳定番ローテ【R】：弥生賞 or スプリングS → 皐月賞 …（G2を使って良オッズ到達を狙う）。

## 3. 配合・血統・継承
- 方式：**種牡馬（父）×繁殖牝馬（母）を1頭ずつ**選んで仔馬生産。親はCPU馬 or 自家製馬。
- **継承タイプ（R固有・3種）**：
  - **H/H**＝ハイリスク・ハイリターン（両親を大幅超えも大幅割れも。分散最大）
  - **平均**＝様々なタイプの仔（中庸の分散）
  - **堅実**＝両親をしっかり引き継ぐ（分散小・安定）。基本は堅実寄りが定石、一発狙いでH/H。
- ⚠ スタホ4の「血統表8頭生産・ニックス・インブリード・18.75%血量・株券ガチャ」は**別タイトル仕様**。Rに同機能がある確証はなく、Rは**継承型ベース**が中心。
- 子に受け継ぐもの：能力（素質ランクの上げ下げ）＋距離/馬場/脚質/気性。定量則はR専用データなし（実例較正が現実的）。
- **自家製馬の血統利用**：**G1勝利した自家製馬**を種牡馬/繁殖に使い、代を重ねて素質を上げるのが上級定石（G1勝利が登録要件か推奨かは文言未確定）。
- 実在モチーフ：**ディープインパクト/ウオッカ**等がCPU種牡馬として配合可。三大始祖系の解放条件は未確定。
- 出典: ameblo/ponyo 12532794780・12532908463, medalgamefan 91, 知恵袋 q10221514295 / q12311922572 / q1340238603

## 4. レース体系・馬券・メダル
### レース
- グレード：**実名JRA準拠**（新馬/未勝利/条件/OP/**G3・G2・G1**）＋**障害**＋架空最上位**WBC / SWBC**（全国対戦・最大5頭マッチング・最高賞金）。
- 三冠＝**皐月賞・東京優駿(ダービー)・菊花賞**。秋古馬三冠＝天皇賞秋・JC・有馬【概念は共通、R実装は要確認】。
- 賞金：**5着以内**で獲得、グレード×着順で増減。実額表は未取得。

### 馬券【共通/2 FINAL公式で列挙】
- 単勝・複勝・枠連・馬連・馬単・ワイド・三連複・三連単 ＋ **ライド系（複勝ライド／メイクライド）** ＋ Colors。
- **メイクライド**＝1着馬を当て、前レース配当を次へ賭けて連勝。オッズ1.1倍以上で多頭買い可＝稼ぎの肝。
- 公式保証：**ベット枚数は着順に影響しない**。
- 「当たりやすい買い方」（1番人気2倍前後、天国/地獄モード等）は**プレイヤー経験則**で裏付け未検証。

### メダル経済
- ベット単位：**1 / 5 / 10 / 50 / 100枚**。
- **メダルバンク（MESTA口座）**で管理、版間移行に言及。
- 増やし方：①ベット（メイクライド連勝）②オーナーゲーム（自馬の賞金）。使い道：ベット原資・生産育成・配合。

## 5. セーブ・周回・寿命・記録ニーズ
- 認証/セーブ：**Aimeカード**＋筐体発行アカウント【4】。スタホRはICカードセーブ世代。
- 保有：**4頭まで**、1レース1頭調教/出走【4】。
- 寿命：**厩舎在籍120週**で引退。**早期引退/継承条件＝G1勝利 or 残80週以下（古馬）**【4】。Rの週数は未確認。
- 代重ね（周回）：引退→繁殖入り→配合で次代へ素質継承。代を重ねるほど素質UP。G1勝利馬は**殿堂馬**登録。
- 既存ツール：**SH4.NET（公式連動）**、**配合シミュレータ（sh4simulator・SH4.NET連携）**、配合シミュシート、gamewiki/wiki、戦績スプレッドシート文化。**いずれもスタホ4中心**。
- **空白（潜在ニーズ）**：残り週カウントダウン＋引退/継承アラート・ローテ/目標レース管理・能力メモを**統合**した管理アプリは未確認。
