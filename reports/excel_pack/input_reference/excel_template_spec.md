# Excelテンプレート仕様

## 基本デザイン
- デザインは案Bベース。
- トップシートはダッシュボード型。
- 詳細シートは案Cベースの実装設計書型。
- 濃紺ヘッダー、ティールのセクション見出し、オレンジの注意、薄赤のリスク、緑のチェックを使用。
- 全シートでFreeze Pane、フィルター、適切な列幅、折り返しを設定。

## 画像の扱い
- 各チームの `images/Txx_architecture.png` をトップシートとアーキテクチャシートに貼り付ける。
- 必要に応じて、Claude Codeで追加図を作成する場合も、表データを削らない。
- 最大1チーム10枚まで画像を許容するが、まずは全体アーキテクチャを必須とする。

## 出力
- 1チーム1Excelファイル。
- T04は除外し、共通資料に除外理由を記載。
