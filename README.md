# Stable Saga — 競走馬 育成シミュレーション（PWA）

自分だけのオリジナル競走馬を作成・育成し、レースに挑むソロプレイの育成シミュレーション。
サーバ不要・オフライン動作・低メンテを最優先に設計したPWA。

## 特徴
- **完全ソロ・オフライン動作**：データは端末内（IndexedDB）。アカウント不要・サーバ不要。
- **育成ループ**：父・母を選んで配合 → ターン制で育成 → レースに出走 → 結果はゲームが算出。
- **入力は選択式中心**：種馬・レースはマスタから選ぶだけ。
- **提案（ルールベース）**：育成方針・次走レースをゲーム設計から提案。
- **フリーミアム**：無料＝厩舎枠2頭・提案 週2回／PRO＝厩舎枠30頭・提案 無制限。
- **消失対策**：JSONエクスポート/インポート、永続ストレージ要求、インストール促進。

## 開発
```bash
npm install
npm run dev        # 開発サーバ
npm run test       # ドメインロジックのテスト（決定論性・ゲート境界）
npm run build      # 型チェック＋本番ビルド（PWA生成）
npm run preview    # ビルド結果のプレビュー
```

## 構成
- `src/domain/` — 純粋ロジック（型・乱数・遺伝・育成・レース算出・提案・課金ゲート）。シード乱数で再現可能・テスト済み。
- `src/data/` — 同梱マスタ（架空の種馬・レース。実名/実データは不使用）。
- `src/db/` — IndexedDB（スキーマ・マイグレーション・CRUD・バックアップ）。
- `src/state/` — アプリ状態（React Context）。
- `src/ui/` — 画面（厩舎／作成／詳細／設定）。
- `src/pwa/` — 永続化・インストール促進。

## 設計メモ
- 全レコードはULID（クライアント生成）＋ `schema_version`。将来のクラウド化時の冪等upsert・移行を見据える。
- 決済は今後 Stripe（Web直販）を統合予定。現状は動作確認用の仮アップグレード。
- 将来クラウド同期するなら Google Drive(appDataFolder) 方式が低メンテで有力（自前サーバ不要）。

詳細な設計判断は計画ドキュメントを参照。
