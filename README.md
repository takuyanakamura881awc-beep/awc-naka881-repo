# Stable Saga — スタホR 管理ツール（PWA）

アーケードゲーム「スターホース プログレス リターンズ（スタホR）」のプレイヤー向け
**コンパニオン／管理ツール**。実機で育てている所有馬のカルテ・出走・配合・寿命(残り週)を
記録・管理する。サーバ不要・オフライン動作・低メンテを最優先に設計したPWA。

## 主な機能（MVP）
- **馬カルテ**：能力・適性・脚質・素質・気性・血統を選択式で記録（手入力を極力排除）。
- **残り週カウントダウン＋引退/継承アラート**：寿命を可視化し、継承可能（G1勝利 or 残80週以下）や残りわずかを通知。
- **ローテ／出走管理**：出走予定（中2週）と結果（着順・オッズ・人気・獲得メダル・馬場）を記録、成績サマリを集計。
- **配合／代重ね**：CPU名馬・引退した自分の馬を父母に選んで血統を記録、世代を引き継ぐ。
- **消失対策**：JSONエクスポート/インポート、永続ストレージ要求、ホーム画面インストール。
- **フリーミアム**：無料＝管理枠2頭／PRO＝30頭。

> 注：寿命の週数・継承条件・能力表記などスタホR固有の数値は公開情報が乏しく、`src/domain/lifecycle.ts`
> 等で既定値として定数化しています（実機で確認して調整可能）。調査の詳細と出典は
> `docs/starhorse-progress-returns-research.md` を参照。

## 開発
```bash
npm install
npm run dev        # 開発サーバ
npm run test       # ドメインロジックのテスト
npm run build      # 型チェック＋本番ビルド（PWA生成）
npm run preview    # ビルド結果のプレビュー
```

## 構成
- `src/domain/` — 型・フリーミアムゲート・ライフサイクル（残り週/継承/成績集計）。テスト済み。
- `src/data/` — スタホRマスタ（CPU名馬・レース。実機で補正可能）。
- `src/db/` — IndexedDB（スキーマ・マイグレーション・CRUD・バックアップ）。
- `src/state/` — アプリ状態（React Context）。
- `src/ui/` — 画面（厩舎／カルテ作成・編集／詳細／出走記録／設定）と選択式フォーム部品。
- `src/pwa/` — 永続化・インストール促進。
- `docs/` — スタホR調査レポート（出典付き）。

## 設計メモ
- 全レコードはULID（クライアント生成）＋ `schema_version`。将来のクラウド化時の冪等upsert・移行を見据える。
- 決済は今後 Stripe（Web直販）を統合予定。現状は動作確認用の仮アップグレード。
- 将来クラウド同期するなら Google Drive(appDataFolder) 方式が低メンテで有力（自前サーバ不要）。
