# 99. 用語集

[← 目次に戻る](./README.md)

---

本資料に登場する主な用語を、SharePoint 初学者向けにかみ砕いて解説します。

| 用語 | 読み／別名 | 説明 |
| --- | --- | --- |
| **Microsoft 365（M365）** | エムサンロクゴ | Office アプリ、Teams、SharePoint、OneDrive、Exchange などを束ねた Microsoft のクラウドサービス群。 |
| **SharePoint Online（SPO）** | シェアポイント | M365 のファイル・情報共有基盤。サイト単位でファイル（ドキュメントライブラリ）やリストを管理する。M365 のファイル系サービスの“土台”。 |
| **OneDrive for Business** | ワンドライブ | 個人用のファイル置き場。実体は「そのユーザー1人が所有者の SharePoint サイト」。 |
| **Microsoft Teams** | チームズ | チャット・会議・通話を軸に、SharePoint やアプリを1画面に束ねる作業ハブ。 |
| **チームサイト** | – | チーム・部門で共同編集するための SharePoint サイト。多くは Microsoft 365 グループと連携し、Teams チーム作成時に自動生成される。 |
| **コミュニケーションサイト** | – | 少数が編集し多数が閲覧する「発信・閲覧」向けの SharePoint サイト。ポータル・規程集・全社周知などに使う。 |
| **ホームサイト／組織全体サイト** | – | 全社の玄関口となる特別なコミュニケーションサイト。イントラのトップページ、公式ニュース源として機能する。 |
| **ハブサイト** | – | 複数のサイトを横串でつなぐ“束ね役”。ナビゲーション共有・横断検索・デザイン統一に使う。サイトの新しい「種類」ではなく役割。 |
| **サブサイト** | – | 親サイトにぶら下げる入れ子のサイト。モダンでは非推奨（フラット構造＋ハブを推奨）。 |
| **クラシック体験／クラシックサイト** | – | 旧来の UI・機能で作られた SharePoint。Microsoft はモダン体験への移行を推奨。 |
| **モダン体験** | – | レスポンシブでモバイル対応、M365 グループ・Teams・ハブと連動する現行の SharePoint 体験。 |
| **Microsoft 365 グループ** | M365 グループ | メンバーの集まりに対し、SharePoint サイト・Teams・予定表・Planner 等をワンセットで結びつける仕組み。共同作業の“場”の単位。 |
| **セキュリティグループ** | – | リソースへのアクセス許可を与えるための「人の束」。付随サービスは持たない。 |
| **配布リスト（配布グループ）** | – | メールを一斉配信するためのグループ。 |
| **標準チャネル** | – | Teams チーム内の通常のチャネル。ファイルは親サイトのフォルダに入り、チームメンバー全員がアクセス可。 |
| **プライベートチャネル** | – | チーム内の指定メンバーだけが見られるチャネル。裏に専用の別 SharePoint サイトが作られる。 |
| **共有チャネル** | – | チーム外（社外・他チーム）を招いて共同作業できるチャネル。相手はチームに参加せず該当チャネルだけ参加。裏に専用の別サイトが作られる。 |
| **サイトコレクション** | – | SharePoint サイトの独立した器の単位。プライベート/共有チャネルの裏サイトは、親とは別のサイトコレクションになる。 |
| **ドキュメントライブラリ** | – | サイト内でファイルを保管する場所。ファイルサーバーの「共有フォルダ」に相当。バージョン履歴・共有・メタデータを備える。 |
| **リスト** | – | 表形式でデータを管理する SharePoint の機能。簡易データベースのように使える。 |
| **メタデータ（列）** | – | ファイルに付ける属性情報（年度・種別・顧客名など）。深いフォルダの代わりに複数軸で分類・検索できる。 |
| **権限レベル** | – | 「フルコントロール」「編集」「読み取り」など、操作できる範囲の定義。所有者/メンバー/閲覧者に割り当てられる。 |
| **権限の継承** | – | サイト→ライブラリ→フォルダ→ファイルへ権限が引き継がれる仕組み。継承を切って個別権限を付けると管理が複雑化する。 |
| **固有の権限** | – | 継承を切って個別に設定した権限。乱発は非推奨。 |
| **既知フォルダ移動（KFM）** | Known Folder Move | Windows の「デスクトップ/ドキュメント/ピクチャ」を OneDrive へ自動同期・保護する仕組み。 |
| **外部共有／ゲスト** | – | 社外の相手にファイル・サイトを共有すること。テナントとサイトの二段階で範囲を設定する。 |
| **共有リンク** | – | ファイル/フォルダへのアクセスを渡すためのリンク。「特定のユーザー」「組織内」「リンクを知っている全員（匿名）」等の種類がある。 |
| **SPMT** | エスピーエムティー | SharePoint Migration Tool。ファイル共有やオンプレ SharePoint を M365 へ移す無償ツール。 |
| **Migration Manager** | – | SharePoint 管理センター内の無償移行機能。複数エージェントで並列・分散移行し、一元管理できる。 |
| **Power Automate** | – | ノーコード/ローコードの業務自動化サービス。旧 SharePoint ワークフローの移行先。 |
| **Power Apps** | – | ノーコード/ローコードで業務アプリ・フォームを作るサービス。InfoPath の移行先。 |
| **SPFx** | エスピーエフエックス | SharePoint Framework。モダン SharePoint のカスタマイズ開発フレームワーク。 |
| **DLP** | データ損失防止 | Data Loss Prevention。機密情報の外部流出を検知・防止する仕組み（フェーズ2の主題）。 |
| **機密ラベル（秘密度ラベル）** | – | 「社外秘」「極秘」等をファイルに付与し、暗号化やアクセス制御を適用する仕組み（フェーズ2の主題）。 |
| **E3 / E5** | – | Microsoft 365 の企業向けプラン。E5 は E3 に高度なセキュリティ・コンプライアンス・電話機能等を追加した上位プラン。 |
